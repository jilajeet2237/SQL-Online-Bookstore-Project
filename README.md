📚 Online Bookstore Analysis using SQL

An end-to-end beginner SQL project where I analysed an online bookstore database using MySQL Workbench.

🎯 Objective

Answer common business questions about books, customers and orders using SQL.

🛠️ Tools Used
MySQL
MySQL Workbench
🗂️ Database Structure
Table	Columns
Books	Book_ID, Title, Author, Genre, Published_Year, Price, Stock
Customers	Customer_ID, Name, Email, Phone, City, Country
Orders	Order_ID, Customer_ID, Book_ID, Order_Date, Quantity, Total_Amount
❓ Questions Solved
All books in the Fiction genre
Books published after 1950
Customers from Canada
Orders placed in November 2023
Total stock of books
Most expensive book
Books sorted by price (high to low)
Customers with orders of quantity > 1 (JOIN)
Orders with total amount greater than $20
All unique genres
Book with the lowest stock
Total revenue
📊 Key Findings
📦 Total stock: 25,056 books
💰 Total revenue: ~$75,628
📚 7 unique genres: Biography, Fantasy, Non-Fiction, Fiction, Romance, Science Fiction, Mystery
🏷️ Most expensive book: Proactive system-worthy orchestration ($49.98)
⚠️ Lowest stock: Future-proofed heuristic function (0 in stock)
🇨🇦 3 customers from Canada
🧠 SQL Concepts Practised

SELECT · WHERE · BETWEEN · ORDER BY · LIMIT · DISTINCT · SUM() · AS · JOIN
